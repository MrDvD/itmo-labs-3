\section{Задание}

\subsection{Содержание работы}

Разработка и расчет марковских моделей одно- и многоканальных СМО с однородным потоком заявок и выбор наилучшего варианта построения СМО в соответствии с заданным критерием эффективности.

В процессе исследований для расчета характеристик функционирования СМО используется программа MARK.

\subsection{Этапы работы}

\begin{enumerate}
    \item Разработка марковских моделей исследуемых систем.
    \item Освоение программы MARK.
    \item Проведение расчетов по разработанным моделям и обработка результатов.
    \item Анализ полученных результатов.
    \item Выбор наилучшего варианта организации системы из двух вариантов в соответствии с заданным критерием эффективности.
\end{enumerate}

\subsection{Порядок выполнения работы}

\begin{enumerate}
    \item Получить вариант работы.
    \item Построить графы переходов для заданных СИСТЕМЫ$_1$ и СИСТЕМЫ$_2$.
    \item С использованием программы MARK рассчитать характеристики марковского процесса для СИСТЕМЫ$_1$ и СИСТЕМЫ$_2$.
    \item Проанализировать характеристики функционирования системы.
    \item Выбрать и обосновать наилучший способ организации системы в соответствии с заданным критерием эффективности.
\end{enumerate}
